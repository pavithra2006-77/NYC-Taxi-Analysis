# NYC Taxi Data Analysis

## Objective
To analyze system behavior and stability using NYC taxi trip data.

## Steps Performed
- Data cleaning and preprocessing
- Time-based behavior analysis
- Stability analysis using aggregation
- Simulation of fare changes

## Tools Used
- Python (Pandas)
- Power BI

## Conclusion
The system shows stable behavior with minor fluctuations. 
Simulation indicates the system responds proportionally to small changes.
